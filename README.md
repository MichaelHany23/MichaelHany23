## 🚀 Featured Projects

### 🧠 LLM-Based Code Generation for PSS: Graduation Project
*Sponsored by Siemens EDA · Ain Shams University · Sep 2025 – Jul 2026*

Evaluates LLM-generated Portable Stimulus Standard (PSS) code.
- Built a benchmark dataset of English-to-PSS-code pairs
- Multi-layered verification using **AST analysis** that catches semantic errors syntax-only checks miss
- **LLM-as-judge** (single-pass and rubric-based) with Qwen2.5-Coder-14B-Instruct, cross-referencing prompts against generated code
- **RAG** pipelines with FAISS, sentence-transformers and cross-encoder reranking, plus PEFT/LoRA fine-tuning and AirLLM memory-efficient inference

### ✈️ [AI Travel Planning Agent](https://github.com/MichaelHany23/ai_travel_planning_agent)
Multi-agent system built with **Google ADK**: a root coordinator delegates to flight, hotel and itinerary specialist agents and merges their outputs into one travel plan with a budget summary. Uses function calling with the Tavily Search API and OpenStreetMap/Nominatim.
`Python` `Google ADK` `Multi-agent` `Function calling`

### 🎯 [Real-Time Object Detection](https://github.com/MichaelHany23/Real-Time-Object-Detection)
YOLOv8 detection on webcam and video with CUDA-accelerated PyTorch and OpenCV. Configurable confidence and CPU/GPU selection, FPS and per-class count overlays, video export, and a **Streamlit** dashboard with in-browser webcam streaming.
`Python` `YOLOv8` `OpenCV` `PyTorch` `Streamlit`

### 🔍 LangGraph Code Review & Auto-Fix Pipeline
Four parallel review nodes (security, performance, style, bug detection) write findings to shared state. A merge node deduplicates and ranks them, then an auto-fix node corrects all critical issues in one pass.
`Python` `LangGraph` `LangChain`

### 📈 [DEPI Graduation Project: US Tech Stock Analysis & Prediction](https://github.com/ahmed-elrewiny/DEPI-Graduation-project)
Data engineering team project analyzing and predicting the performance of U.S. technology sector stocks.
`Jupyter Notebook` `Data Engineering`
